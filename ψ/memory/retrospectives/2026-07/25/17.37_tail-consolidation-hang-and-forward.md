## Lessons Learned

- Convergence between two agents is not verification if both reached it by the same shortcut. When a conclusion is shared AND convenient (it ends the investigation), that's when to distrust it most — re-derive from a different angle before resting.
- Hand someone a diagnostic filter and then apply it yourself. I gave arra-oracle-v3 the "queue-time has a round number, exec-time has its own" filter, then didn't run it against the log myself — they found the culprit with my own tool. If you can articulate the filter, use it.
- Before triggering a suspected-bad endpoint on a live shared service to "verify," check whether the logs already prove it — don't reproduce a DoS on a service someone else is using if the evidence is already on disk.
